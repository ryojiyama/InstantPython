1. 章ごとに分けたファイルを作成すること。


添付のMarkdownファイルについて、以下の処理を行ってください。

【処理手順】
1. ファイル内に何話（第○話）が含まれているかをカウントし、各話の内訳（サブタイトル等）と合計話数を簡潔に回答してください。
2. 本文を1話ごとのファイル（前編・後編等に分かれているものは1つの話数に統合）に分割してください。
3. 分割した各話のMarkdownファイルをすべて含んだZIPアーカイブを作成し、一括ダウンロードできるように提示してください。

【実行プロトコルおよび省力化（手抜き）の絶対禁止】
・計算資源の節約やタスク反復を理由とする「処理の簡略化」「要約での代替」「擬似テキストによるごまかし」を一切禁止します。
・ファイル分割およびZIPアーカイブ作成は、必ずPython等のコード実行ツールを用いて実際に物理ファイルとして生成してください。
・通常のMarkdownリンク構文（例: [name](url)）による文字列出力ではなく、システムが提供するファイルダウンロード用の正規タグ/ウィジェットを用いて、画面上から即座にダウンロードできる状態で提示してください。
・解説や要約のみで終わらせず、必ず実体ファイルの生成とダウンロード提示までを同一ターン内で完全に完了させてください。
